# 💻 Crypto Hackathon Project

This project was developed as part of the Schelling Point Virtual Hackathon on Gitcoin, completed within a single day. The web application provides real-time cryptocurrency news and statistics, fetched from external APIs. It is built with React and TypeScript, using modern web technologies like Tailwind CSS for styling and Chart.js for data visualization. The app also supports dark and light themes, ensuring a seamless user experience across devices. The project is fully functional, responsive, and deployed on Vercel.

## ✨ Features

- **Real-time Crypto Stats:** Fetches up-to-date cryptocurrency data and news from Rapid API.
- **Data Visualization:** Uses Chart.js to display market trends and statistics in an easy-to-understand format.
- **Dark/Light Theme Toggle:** Users can switch between dark and light modes for an optimal viewing experience.
- **Responsive Design:** Tailwind CSS ensures the app looks great on any device.
- **State Management:** Redux is used for managing global state across the application.
- **Environment Variables:** .env file is included for showcasing API keys and other environment variables.

## 🛠️ Tech Stack

- **Frontend:**
  - [React](https://reactjs.org/) with [TypeScript](https://www.typescriptlang.org/)
  - [Tailwind CSS](https://tailwindcss.com/)
  - [Chart.js](https://www.chartjs.org/)
  - [Redux](https://redux.js.org/)
- **API:**

- **Deployment:**
  - [Vercel](https://vercel.com/)
